# 渊之鱼冥下载站 (YZYM Download Station)

> 专为校园信息课与游戏爱好者准备的资源仓库 —— 无需登录，高速下载

## 项目简介

渊之鱼冥下载站是 YuanZhiYuMing 的个人资源仓库站点，基于 GitHub Pages 托管运行。本站专注收录各类实用资源，核心为 Minecraft 游戏资源，同时涵盖影视歌曲、学习资源、常用工具及校园信息课必备软件。

所有文件均经过精心整理，适配学校机房环境（无音频、轻量化、免安装），无需登录即可高速下载。

## 快速开始

点击首页「极速开始」按钮，自动下载并运行下载程序。

如需手动下载，可前往 Minecraft 专区下载所需文件；需要加速时，先安装 IDM，再复制下载链接新建任务。

## 使用指南

### Minecraft 启动

1. 双击自解压程序 `SURVIVAL_hmcl_1.21.11.exe`，点击 Extract 继续
2. 解压后打开文件夹，双击 `HMCL.exe`
3. 弹窗点击「同意」，左侧「账户」添加账户，选择离线模式，输入名字并登录
4. 左上角返回，「通用」→「设置」→ 开启「不检查游戏完整性」
5. 返回点击「启动游戏 1.21.11」

### JiYuTrainer 使用

开源项目：[imengyu/JiYuTrainer](https://github.com/imengyu/JiYuTrainer)

- 将极域全屏广播转为窗口模式
- 内置强杀 / 启停极域进程功能
- 破解极域解锁卸载密码
- 反监视与防控制功能

操作：双击运行 `JiYuTrainer.exe` → 点击「我同意」→ 最小化即可。

> 某些杀毒软件可能报毒，需关闭或添加白名单。

### IDM 使用（可选）

官网：[Internet Download Manager](https://www.internetdownloadmanager.com)

1. 下载并安装 `idm642build63.exe`
2. 浏览器下载目标文件 → 取消下载 → 复制下载链接
3. 打开 IDM → 新建任务 → 粘贴链接 → 开始下载

### 歌曲下载

- **单曲下载**：歌曲列表每行右侧的下载按钮，直达蓝奏云链接
- **下载全部**：支持「下载文件夹」（huang1111 网盘总链接，可在线预览收听）与「下载.zip」整包下载
- **下载歌词**：一键前往歌词网盘页面，获取全部歌词文件

### 常见问题（铃铛提示）

- **在线收听**：点击「下载全部」→「下载文件夹」，在 huang1111 网盘页面可预览所有歌曲并收听
- **歌曲链接无法查看**：可能被蓝奏云因版权封禁，请于首页反馈曲目名称；期间可通过「下载文件夹」选择曲目下载
- **电影付费问题**：安装 123 云盘客户端即可免费下载（每月 10GB 额度）

## 技术特性

- 前端技术：纯 HTML5 + CSS3 + Vanilla JavaScript
- UI 设计：Glassmorphism（毛玻璃）风格 + 纯 SVG 手绘电影卡片（像素风苦力怕 / 盗梦空间城市 / 星际穿越黑洞），响应式布局
- 主题系统：CSS 自定义属性实现明暗双主题，按时间自动切换
- 交互效果：自定义光标动画、磁性按钮、铃铛悬停展开动画、弹窗遮罩模糊等
- 国际化：自研 i18n 模块，7 种语言全量翻译
- 部署方式：GitHub Pages
